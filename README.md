# ELITE XI — Cricket Performance Academy

A static HTML/CSS/Vanilla JavaScript redesign based on the supplied ELITE XI redesign specification.

## Structure
- `index.html`
- `pages/program.html`
- `pages/coaches.html`
- `pages/facilities.html`
- `pages/about.html`
- `pages/register.html`
- `css/style.css`
- `css/responsive.css`
- `css/intro.css`
- `js/main.js`
- `js/animations.js`
- `js/forms.js`
- `assets/`

## Run
Open `index.html` in a modern browser. No build step or backend is required.

## Notes
- Local high-resolution photography is stored under `assets/images/` for fast, offline-ready presentation.
- To update or replace the Founder photo in the About section with your own personal photograph, simply save your image file as `assets/images/irshad.jpg`.
- The coaches section features Virat Kohli (Batting), Jasprit Bumrah (Bowling), Ravindra Jadeja (Fielding), and Smriti Mandhana (Senior Batting Mentor & Strokeplay Specialist).
- The registration form validates locally and shows a success state; it does not submit to a backend.
- The site uses no React, Next.js, database, authentication, glassmorphism, dark dashboard cards, or neon effects.
